Duxreader's first test release brings your desktop palette to websites and Vimium overlays.

- Pywalfox browser-theme sync on Firefox and Matugen JSON support through the optional Rust bridge.
- Dynamic page colors, semantic-color preservation and GitHub theme mappings.
- Integrated Vimium navigation, a Material 3 Preferences page and selectable UI fonts.
- Duxlogo branding and interaction benchmarks.

### Install

- **Chromium / Edge:** extract `duxreader-0.1.0-chromium-edge.zip`, enable Developer mode, and use **Load unpacked** at `chrome://extensions` or `edge://extensions`.
- **Firefox:** extract `duxreader-0.1.0-firefox-unsigned.zip` and load `manifest.json` at `about:debugging`. This temporary installation lasts until Firefox closes. If a `firefox-signed.xpi` asset is attached, use **Install Add-on From File** in `about:addons` instead.
- **Theme-file mode:** the optional native bridge currently has a Linux registration helper. Firefox's Pywalfox mode does not need it.

See `INSTALL.md` for setup and `SHA256SUMS` to verify downloads. These are test packages; browser-store listings are not included.
