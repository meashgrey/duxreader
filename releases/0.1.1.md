Duxreader 0.1.1 turns the element picker into a usable repair tool and keeps your rules portable.

- **Pick anything and fix it in place.** Choose Preserve or Map in the popup, or press `Alt+Shift+E` / `Alt+Shift+M` on the page. Hover shows the exact element plus every sibling the saved rule would also change.
- **Rules target components, not accidents.** Generated class hashes collapse to component prefixes, stable `data-*` attributes, route prefixes, and structural families are preferred over instance paths, and overlapping or nested boxes can be stepped through with the arrow keys before clicking.
- **Shadow DOM is covered.** Elements inside open shadow roots can be picked, and their rules are injected into the owning shadow root instead of leaking into the page.
- **Preserve only what the family actually shares.** Filters, dividers, and first-row rules no longer freeze every sibling to one snapshot; genuinely mixed colours offer per-element preservation instead.
- **Rules are editable and portable.** Re-target a map rule to another theme role, undo a removal, review every rule grouped by site in Preferences, and export or import the whole set as JSON.

### Install

- **Chromium / Edge:** extract `duxreader-0.1.1-chromium-edge.zip`, enable Developer mode, and use **Load unpacked** at `chrome://extensions` or `edge://extensions`.
- **Firefox:** extract `duxreader-0.1.1-firefox-unsigned.zip` and load `manifest.json` at `about:debugging`. This temporary installation lasts until Firefox closes. If a `firefox-signed.xpi` asset is attached, use **Install Add-on From File** in `about:addons` instead.
- **Theme-file mode:** the optional native bridge currently has a Linux registration helper. Firefox's Pywalfox mode does not need it.

See `INSTALL.md` for setup and `SHA256SUMS` to verify downloads. These are test packages; browser-store listings are not included.
